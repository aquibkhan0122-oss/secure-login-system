# 🔐 Secure Login System

A secure and user-friendly authentication system built with Python and Flask.

This project provides user registration and login functionality with password protection and session-based authentication.

## 🚀 Live Demo

**Live Application:**  
https://secure-login-system-k2ys.onrender.com

> The application is deployed on Render's free instance, so the first request may take some time if the server has been inactive.

---

## ✨ Features

- 🔐 User Registration
- 🔑 User Login
- 🚪 User Logout
- 🔒 Secure password hashing
- 🛡️ Session-based authentication
- ✅ Form validation
- 🗄️ Database-backed user authentication
- 📱 Simple and responsive user interface
- 🌐 Cloud deployment using Render

---

## 🛠️ Technologies Used

- **Python** — Backend programming
- **Flask** — Web framework
- **HTML5** — Frontend structure
- **CSS3** — Styling
- **SQLite** — Database
- **Werkzeug** — Password hashing
- **Gunicorn** — Production WSGI server
- **Render** — Cloud deployment
- **Git & GitHub** — Version control
